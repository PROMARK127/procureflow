# 購買業務と担当者

1. 購入者が商品・数量・理由を登録すると、申請番号と承認経路が自動生成される。
2. 部門承認者は承認、差戻し、却下を行う。10万円以上の申請は、部門承認の後に購買責任者が判断する。差戻しは購入者が修正して再申請でき、旧ラウンドの履歴も参照できる。
3. 購買責任者が異なる2社の見積を登録し、採用理由と採用先を記録する。購入者が採用見積で発注する。承認額を超える場合は新規申請が必要。
4. サプライヤー担当者は自社の発注を閲覧し、確認を登録する。購入者は受領数量を一括で登録する。結果は数量一致なら完了、不足なら不足となる。
5. 経理担当者は請求額と請求日を登録する。発注と検収の数量、発注と請求の金額を照合し、合致した未払い請求を支払完了に更新する。

デモ担当者は画面右上で選択する。更新時は管理用PINを入力する。デモのサプライヤー担当は東都IT商事に所属する。ほか2社も見積と発注の対象になる。
